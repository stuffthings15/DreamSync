# DreamSync Device Lab

The authoritative usage guide is `Documents\DreamSync\docs\USB_DEVICE_LAB.md`.

Raw runs belong under:

`hardware-validation\<UTC-date>\<run-id>\`

Do not upload or commit raw runs automatically. Preserve failed runs and corrected
reruns. A registration result is not sensor proof; require changing values and the
minimum callback counts. Play-signed Internal builds are required for final Samsung
package/signature conclusions.
