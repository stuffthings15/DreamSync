# DreamSync source provenance

DreamSync is currently maintained under the product name DreamSync, publisher Remote, and package `com.remote.DreamSync`.

The live source tree includes work derived from an earlier prototype archive. The repository `LICENSE` records Remote ownership, but that file alone does not prove written transfer or original authorship for every inherited component.

## Release boundary

- Private/internal testing may continue for capstone and engineering validation.
- Public production publication remains blocked until Remote has written evidence covering ownership or permission for all inherited source and assets.
- Third-party Android, Google Play services, AndroidX, and Samsung SDK components remain governed by their own licenses and program terms.
- The optional Samsung Health Sensor SDK AAR is not stored in this repository and must be obtained through Samsung's approved distribution path.

No provenance statement should be interpreted as a medical, clinical, or efficacy claim.
